# GTM Automation Portfolio

Prototype GTM workflows built with sample data to demonstrate lead routing and CRM automation logic.

By Ansh Mishra | [LinkedIn](https://www.linkedin.com/in/ansh-mishra-280b67193/)

---

## 1. Multi-Source GTM Automation (n8n)

![n8n workflow](n8n-workflow.png)

Built a GTM automation prototype in n8n for handling leads from multiple sources.

**Flow:** Multi-source lead intake → Lead normalization → Reply/qualification check → HubSpot CRM → Sales notification

The workflow shows how different lead sources can be brought into one automated GTM workflow and routed through a common CRM process.

**Tools:** n8n, Google Sheets, HubSpot, Gmail

## 2. GTM Lead Routing & CRM Automation (Zapier)
